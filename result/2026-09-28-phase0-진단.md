## 우선순위 제안

### A. 코드로 바로 (오늘)
1. Stats SSR 초기값 = 최종값 (애니메이션은 클라에서만 0부터)
2. FAQ 아임웹 문구 수정(사실 확인 필요) + FAQPage JSON-LD
3. 메타 키워드 정렬: 메인 description, 서비스 title/description, 서브 title
4. Hero h1에 "부천 홈페이지 제작" 포함 (eyebrow 또는 h1 첫 줄)
5. Organization → ProfessionalService(LocalBusiness 계열) + streetAddress·postalCode·telephone·geo
6. 서비스 페이지에 가격표(Pricing 재사용) + Service/Offer 스키마
7. sitemap lastmod 실제 수정일 (정적 페이지는 상수 날짜)
8. `/terms`, `/privacy` 페이지 생성 (개인정보처리방침은 문의폼 있으니 법적으로도 필요)
9. 푸터에 전화번호

### B. 콘텐츠 (주 1~2건)
10. 질문형 칼럼 + 의미 있는 슬러그: 홈페이지 제작 비용 / 제작 기간 / 업체 고르는 법 / 템플릿 vs 맞춤형 / 유지보수 비용
11. `/부천-홈페이지-제작`(또는 `/bucheon`) 지역 랜딩: 부천·인천·서울 서부 대상, 방문 미팅 가능 여부, 부천 고객 사례
12. 포트폴리오 상세 라벨-값 구조(업종·페이지 수·기간·기술·결과)

### C. 계정 작업 (사용자)
13. 네이버 스마트플레이스 등록 (주소 동일하게) — "부천 홈페이지 제작"은 플레이스 영역이 상단
14. 구글 비즈니스 프로필 등록 — 구글 로컬팩
15. 네이버 블로그 개설 → 칼럼 요약 + 원문 링크, `sameAs` 추가
16. 서치어드바이저·서치콘솔 사이트맵 재제출

## 기대치
- "부천 홈페이지 제작": 경쟁 약함. A + 플레이스/GBP 등록이면 수주~2개월 내 1페이지 현실적.
- "홈페이지 제작" 단일 키워드: 도메인 이력·콘텐츠 양 싸움이라 수개월~1년 단위. 칼럼 누적이 핵심.

- 네이버/구글 실제 순위 측정 — 기준선은 배포 후 수동 기록 필요
